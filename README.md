# Thuto's Arcade

A mobile-first browser arcade inspired by quick, turn-based party games. The single-page interface includes pool, basketball, cup pong, mini golf, archery, darts, Knockout, Word Hunt, Anagrams, and Word Bites, with CPU and local two-player modes where implemented.

## Run

Open `index.html` in a modern browser. Three-dimensional games load Three.js and Cannon-es, and physics games load Matter.js from jsDelivr, so those games require an internet connection. The game suite is a work in progress; game behavior and browser compatibility may vary.

## Project description

Thuto's Arcade is a mobile-first web arcade with canvas-based party games, turn-based CPU and local multiplayer modes, pool, sports, target, and word games.
